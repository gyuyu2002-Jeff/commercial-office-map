主來源為財政部財政資訊中心「全國營業（稅籍）登記資料集」，涵蓋來源檔案中的全國營業中營業人；停業、歇業等歷史資料不在這份資料集內。營業人包含公司、商號及其他組織，不限商辦租戶。

財政部資料集說明下載官方原始資料 ZIP政府資料開放授權條款

資料版本與更新

載入擷取時間與資料版本中…

財政部來源標示每日更新；本站顯示本次成功擷取與發布的資料版本，並非即時查詢。來源檔未提供逐筆最後異動時間。資料依原始欄位呈現，不以推測填補缺漏。

包含哪些欄位

財政部資料包含營業地址、統一編號、總機構統一編號、營業人名稱、資本額、設立日期、組織別、是否使用統一發票，以及最多四組行業代號與名稱。

上市及上櫃公司依統編比對臺灣證券交易所與證券櫃檯買賣中心的公司基本資料，補充有提供的股票代號、公司總機、董事長與官方網站。沒有比對到的欄位顯示未提供；董事長不等同所有組織的登記負責人。

證交所上市公司基本資料櫃買中心上櫃公司基本資料商工登記公示查詢

登記地址與地圖的範圍

「登記地址名錄」依目前篩選結果的完整原始地址分組，並未驗證大樓名稱、實際進駐租戶、營業現況或樓層使用情形。相同地址也可能是登記或代收地址。

地圖標記是行政區的概覽點與營業人筆數，不是公司座標。行政區概覽點由國土測繪中心公開界線資料計算；地址無法辨識行政區時仍保留在名單，不以假座標補點。個別地址可由卡片開啟外部地圖搜尋，請確認實際位置後再前往。

拜訪紀錄與備份

拜訪狀態與預設縣市僅儲存在目前裝置的瀏覽器，不會上傳或跨裝置同步。清除網站資料、使用無痕模式或瀏覽器儲存失敗時，紀錄可能遺失。

請從「更多」選擇「備份拜訪紀錄」下載 JSON 檔；還原時會合併備份中的有效紀錄。請妥善保管備份檔。本站不寄送更新郵件。

定位與外部服務

只有按下「我的位置」後，本站才會向瀏覽器請求定位權限；取得的位置僅用於目前地圖，不儲存於拜訪紀錄。

底圖由 OpenStreetMap、國土測繪中心或 Esri 提供。載入底圖時，所選服務會收到網路請求，可能包含 IP 位址與地圖範圍。開啟外部地圖搜尋會將選定登記地址傳給該服務，各服務依自身政策處理。
