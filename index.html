開啟網站後的預設

先顯示資本額 1,000 萬元以上（含）的企業，上市、上櫃公司排在前面，其餘符合條件的企業也會保留。縣市預設為桃園市，或你上次選擇記住的縣市。

路過只知道大樓名稱

按上方「找大樓」，輸入招牌名稱，例如「世貿帝國」「國際金融廣場」「中壢中國信託」。比對地址後選取大樓，系統會切換到該縣市、清除其他公司條件，並保留目前資本額門檻。符合條件的上市櫃企業仍優先。

大樓摘要列出已核對的門牌、各門牌本期收錄筆數、核對日期與來源。按「查看本棟全部收錄企業」可取消資本額及其他企業條件，保留大樓範圍。這是登記企業與潛在拜訪名單，沒有接入你們的既有客戶資料。

名稱清冊按全台縣市分批核對，可從「找大樓」的縣市選單查看已核對棟數。尚未收錄名稱的地區可用「查詢本縣市企業與門牌」繼續搜尋。名稱搜尋不受資本額或公司條件限制，也可在主搜尋框輸入大樓名稱；零筆不代表大樓沒有企業。多門牌大樓只比對已核對門牌，登記不等於現場實際進駐。

1. 選地區，再輸入關鍵字

按「切換縣市」選擇範圍，再從上方列選行政區。搜尋可輸入公司名稱、統編、股票代號或地址，也可組合輸入「華懋 中壢」；每個空白分隔的關鍵字都要符合，但可分別出現在名稱或地址等不同欄位。

台／臺、全形／半形與英文字母大小寫都會自動統一比對。停止輸入後會自動搜尋，也可按 Enter 或「搜尋」。輸入建議最多顯示六家符合目前條件的真實收錄企業，可直接選取名稱。

切換縣市或行政區會保留關鍵字、產業、資本額、上市櫃與拜訪條件；原大樓條件會取消。切換縣市也會取消原行政區。

2. 用條件縮小名單

按「篩選條件」可選產業、資本額、商辦大樓、上市櫃及拜訪進度，選取後立即更新。產業先按大類分組，相同名稱已合併；分類依來源第一項登記行業。

例如同時選「只看上市櫃」與「尚未拜訪」，找出還沒拜訪的上市櫃企業。只顯示已由官方資料統編比對確認的上市櫃公司，不推測其他企業的市場身分。

搜尋框下方顯示已套用條件，點條件旁的「×」可單獨取消。「恢復預設」會清除關鍵字與其他條件，回到目前縣市、資本額 1,000 萬以上；「清除關鍵字與全部條件」則包含取消資本額限制。

3. 看公司與大樓資料

卡片先顯示統編、登記地址、資本額及主要行業。「查看完整資料」保留完整金額、設立日期、組織別、統一發票、所有登記行業與有提供的上市櫃資訊。未提供的欄位不會自行補填。

「找大樓 → 目前結果的門牌」依目前篩選結果的棟別地址彙整；選取門牌後，保留其他企業條件。名稱清冊與目前結果的門牌清冊範圍不同，前者只包含已查證名稱的大樓。

「查登記地址」會開啟外部地圖搜尋。本站地圖的圓點與數量是行政區概覽，不是公司的精確位置；登記地址也不保證實際進駐情況。

4. 記錄拜訪、匯出與備份

在公司卡片選「尚未拜訪」「洽談中」或「已拜訪」，狀態會存於目前瀏覽器。預設的「尚未拜訪」代表尚無本機拜訪紀錄。若套用拜訪篩選，改狀態後公司可能離開目前名單。

從「更多 → 匯出篩選名單 CSV」可下載所有符合條件的結果，不限畫面上已顯示的 40 筆；請等搜尋完成。用 Excel 匯入時，統編欄設為文字，才能保留開頭的 0。

「更多 → 備份拜訪紀錄」下載 JSON；更換裝置後用「還原拜訪紀錄」合併紀錄，相同統編以備份狀態覆蓋。紀錄不會自動同步，清除瀏覽器資料前請先備份。本站沒有寄信功能。

找不到時怎麼辦？

先確認縣市與條件標籤，再使用結果區的按鈕取消資本額條件、清除關鍵字或切換縣市。本站只搜尋依商辦條件收錄的官方登記資料；零筆結果不代表公司不存在。資料範圍、來源日期及更新方式可在「資料說明」查看。

電腦上方可選「放大名單」「名單＋地圖」「地圖」；手機下方可切換「名單」「分割」「地圖」。找公司時先用名單，再按需要查看區域分布。

資料版本與更新

載入擷取時間與資料版本中…

財政部來源標示每日更新；本站顯示本次成功擷取與發布的資料版本，並非即時查詢。來源檔未提供逐筆最後異動時間。資料依原始欄位呈現，不以推測填補缺漏。

包含哪些欄位

財政部資料包含營業地址、統一編號、總機構統一編號、營業人名稱、資本額、設立日期、組織別、是否使用統一發票，以及最多四組行業代號與名稱。

上市及上櫃公司依統編比對臺灣證券交易所與證券櫃檯買賣中心的公司基本資料，補充有提供的股票代號、公司總機、董事長與官方網站。沒有比對到的欄位顯示未提供；董事長不等同所有組織的登記負責人。

商辦大樓名錄與地圖範圍

大樓名稱清冊按全台縣市分批核對，桃園以建築管理處管理組織清冊為主要來源，其他地區採政府、營運單位、使用單位及不動產公開資料核對。各棟附核對日期與來源；各縣市名稱收錄進度不同，可在縣市選單查看。不代表完整覆蓋或建築用途認定。名稱清冊與企業快照分開更新，並非每日自動查證招牌名稱。

桃園市建築管理處大樓管理組織清冊

「商辦大樓名錄」依正規化棟別地址（移除里鄰並合併中文段數寫法）彙整目前篩選結果；同一棟別門牌可能包含商務中心或多家登記企業，實際樓層與現場進駐情形仍請現勘確認。

地圖標記是行政區的概覽點與樓內企業筆數，不是公司精確門牌座標。行政區概覽點由國土測繪中心公開界線資料計算；個別地址可由卡片開啟外部地圖搜尋。

拜訪紀錄與備份

拜訪狀態與預設縣市僅儲存在目前裝置的瀏覽器，不會上傳或跨裝置同步。清除網站資料、使用無痕模式或瀏覽器儲存失敗時，紀錄可能遺失。

請從「更多」選擇「備份拜訪紀錄」下載 JSON 檔；還原時會合併備份中的有效紀錄。請妥善保管備份檔。本站不寄送更新郵件。

定位與外部服務

只有按下「我的位置」後，本站才會向瀏覽器請求定位權限；取得的位置僅用於目前地圖，不儲存於拜訪紀錄。

底圖由 OpenStreetMap、國土測繪中心或 Esri 提供。載入底圖時，所選服務會收到網路請求，可能包含 IP 位址與地圖範圍。開啟外部地圖搜尋會將選定登記地址傳給該服務，各服務依自身政策處理。
