拜訪紀錄與備份

拜訪狀態與預設縣市僅儲存在目前裝置的瀏覽器，不會上傳或跨裝置同步。清除網站資料、使用無痕模式或瀏覽器儲存失敗時，紀錄可能遺失。

請從「更多」選擇「備份拜訪紀錄」下載 JSON 檔；還原時會合併備份中的有效紀錄。請妥善保管備份檔。

定位與外部地圖

只有按下「我的位置」後，本站才會向瀏覽器請求定位權限；取得的位置僅用於目前地圖，不儲存於拜訪紀錄。

地圖底圖由 OpenStreetMap、國土測繪中心或 Esri 提供。載入底圖時，所選服務會收到網路請求，可能包含 IP 位址與目前地圖範圍；各服務依自身政策處理。
