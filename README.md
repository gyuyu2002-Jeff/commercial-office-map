# 全台商辦＆企業地圖

[開啟網站](https://gyuyu2002-jeff.github.io/commercial-office-map/)

這是商辦地圖與拜訪管理的**示範工具**。原始企業名錄由程式合成，沒有串接政府資料或查證企業進駐情況；建物名稱、位置與樓層也未完成來源核實，不能作為真實拜訪或營業登記依據。

公開網站使用中性示範企業名稱，不顯示原本隨機生成的電話、統編或負責人，不提供示範企業電話直撥或拜訪導航。資本額、分類與上市櫃條件僅用於展示篩選功能。

## 功能

- 22 縣市切換，依商圈、產業、資本額、建物、拜訪狀態及文字搜尋。
- 清單與地圖共用篩選結果；每次顯示有限筆數，避免一次建立整縣企業卡片。
- 大樓名錄、地圖縮放、標籤、三種底圖，以及使用者主動要求的位置定位。
- 拜訪狀態僅儲存在目前瀏覽器，可下載 JSON 備份並還原；篩選結果可匯出標示為示範資料的 CSV。
- 手機清單／地圖／分割檢視，鍵盤操作、對話框焦點管理及減少動態效果。

## 資料與紀錄

`commercial_database_taiwan.json` 是歷史合成輸入，不是官方資料。`build_commercial_html.py` 會清除虛構聯絡資訊與預灌的業務進度，建立固定的示範企業識別碼，輸出縣市目錄及各縣資料。網站只載入目前需要的縣市。

舊版 `commercial_status_overrides_v2` 中由使用者手動儲存的有效狀態會遷移到新版；合成資料中的「洽談中／已拜訪」不會被當成個人紀錄。舊版鍵值會保留，以便復原。新版備份只包含拜訪紀錄，不包含帳號或定位資訊。清除瀏覽器網站資料、使用無痕模式或換裝置可能讓本機紀錄消失，請先備份。若瀏覽器拒絕儲存，網站會提示。

建置時間只代表網頁產生時間；資料版本由內容計算，並不代表來源已查核或官方資料已更新。正式使用前需另外取得可信企業與據點資料、來源 URL、查核日期及穩定識別碼。原有的每月更新宣稱、排程寄信與 SMTP 程式已取消。

## 本機執行

需要 Python 3.11 以上，建置不需要安裝第三方套件。

```powershell
python build_commercial_html.py
python serve_local.py
```

Windows 也可雙擊 `啟動商辦企業地圖.bat`。本機固定使用 `http://127.0.0.1:18765/`，讓重新啟動後仍能讀取同一份瀏覽器紀錄。不能直接雙擊 HTML 檔案；JSON 資料載入需要 HTTP。底圖仍需要網路連線。

## 驗證與部署

```powershell
python build_commercial_html.py
python -m unittest discover -s tests -p "test_*.py" -v
node --test tests/core.test.js
node --check assets/app.js
```

編輯 `src/index.html`、`assets/styles.css`、`assets/app.js` 或資料建置程式，再執行建置。`index.html` 是生成檔，不應直接修改。

推送 `main` 後，GitHub Actions 會執行測試、建置並將 `dist/` 發布到原 GitHub Pages 網址。Pages 設定使用 **GitHub Actions**。只有靜態網站成品會部署，歷史資料、Python 程式及測試不在發布目錄中。部署流程不寄信，也不宣稱已同步政府資料。

## 圖資與隱私

Leaflet 1.9.4 隨站提供，授權見 `assets/vendor/leaflet/LICENSE`。底圖使用 OpenStreetMap、內政部國土測繪中心與 Esri，各圖層保留來源標示；使用限制依各供應者條款。外部圖資供應者會收到瀏覽器的 IP 與所請求圖磚範圍。定位只在點擊「我的位置」並取得瀏覽器授權後使用，不上傳到本站伺服器；定位後載入的外部底圖可能反映該區域。網站沒有帳號、郵件通知或後端拜訪紀錄同步服務。
