## 🌟 核心設計特色

### 1. 排除沿街無效零售，聚焦商辦與總部
自動過濾沿街小吃便當、手搖飲料、美甲美容、機車行、投幣洗衣等非辦公室型態店家，專注於：
* 💻 **IT 資訊與軟體研發**
* ⚖️ **專業商務服務（會計師、律師、專利事務所、企管顧問）**
* 📐 **建築工程與室內設計事務所**
* 🌐 **跨國進出口貿易商**
* 🏦 **金融保險與資產管理**

### 2. 四大高價值邊界行業（A、B、C、D）專屬勳章快篩
* 🏢 **⭐ A. 商務中心 / 共享辦公 (Co-working)**：弱電主機、大量獨立門禁卡機、多組獨立 VLAN 網路架設的高毛利客群。
* 🩺 **⭐ B. 牙醫醫美診所 / 專科體系 (Clinic)**：高規監視系統、隱私門禁、病歷電子化伺服器防護需求。
* 🍔 **⭐ C. 連鎖餐飲零售「企業營運總部」 (Corporate HQ)**：全台分店總部中央監控、總部會議室視訊系統。
* 🚢 **⭐ D. 物流倉儲·海空運承攬總部 (Logistics)**：大廠區與辦公室混合弱電、長距離光纖佈線、海關保稅監控需求。

### 3. 業界首創「商辦大樓水牌模式」（樓層垂直堆疊）
* 針對同一棟摩天商辦內聚集數十家公司的垂直空間特點，點擊指標大樓即可展開如一樓大廳水牌般的名錄。
* 依樓層（如 `32F`、`31F` ... `2F`）依序排列表列，便於外勤業務人員搭電梯「樓上樓下一層一層連續掃樓拜訪」，免重複上下奔波！

### 4. 完整外勤工具鏈
* **地圖放大自動顯名**：縮放到高倍率（Zoom >= 16）自動浮現大樓與商辦名稱標籤，免逐一摸索。
* **拜訪狀態常駐維護**：支援「尚未拜訪」、「洽談中」、「✅ 已拜訪」等自訂業務階段，儲存於瀏覽器本機。
* **一鍵導航與電話直撥**：快速呼叫 Google Maps 規劃路線。
* **名單繁體中文匯出**：篩選後一鍵匯出 CSV，無縫對接 CRM 或業務報表。
* **高質感 Skyline 摩天商辦 Favicon**：支援手機「加入主畫面」與桌面捷徑圖示。
