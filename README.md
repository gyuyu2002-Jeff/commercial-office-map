# 全台商辦大樓地圖

[開啟網站](https://gyuyu2002-jeff.github.io/commercial-office-map/)

使用財政部公開的**全國營業中稅籍登記快照**，經多樓層商業辦公大樓門牌群聚與法人條件篩選後，僅收錄商業辦公大樓與樓內進駐企業（排除一般街邊店面、工廠與單戶登記），提供營業人名稱、統編、樓層地址、資本額、設立日期、組織別、統一發票及最多四組行業資料。沒有合成企業、隨機電話、虛構進駐樓層或預設拜訪紀錄。

## 資料來源與範圍

- [財政部財政資訊中心：全國營業（稅籍）登記資料集](https://data.gov.tw/dataset/9400)：每日公開更新，含營業中登記，不含歷年停歇業資料。本站保留符合商辦篩選條件的紀錄及其 16 個原始欄位，實際來源日期與收錄筆數可在網站「資料說明」查看。
- [證交所上市公司基本資料](https://openapi.twse.com.tw/v1/opendata/t187ap03_L)、[櫃買中心上櫃公司基本資料](https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap03_O)：以完全相同的統編補充股票代號、公司總機、董事長、官方網站。公司總機不是各分店電話，董事長不是所有組織的登記負責人。沒有對應到時不推測上市櫃狀態或聯絡資訊。
- [國土測繪中心鄉鎮市區界線](https://data.gov.tw/dataset/7441)：368 個行政區的概覽點，由最大陸塊內點計算。地圖呈現行政區筆數，**不是企業精確座標**。
- [財政部稅務行業標準分類](https://data.gov.tw/dataset/28483)：第 9 次修訂中類對照；未辨識代碼照原值保留。
- [桃園市建築管理處大樓管理組織清冊](https://oba.tycg.gov.tw/News_Content.aspx?n=8696&s=1620845)：使用更新至 2026-10-31 的清冊，第一批整理 43 棟大樓名稱、46 個核對門牌，涵蓋桃園、中壢、龜山、蘆竹、八德。`config/named_buildings.json` 記錄原始工作表／儲存格、來源名稱與地址、下載檔雜湊、核對日期；部分別名及其他門牌另附公開來源。含商住混合大樓，不作建築用途認定，也不宣稱完整覆蓋桃園。

「完整」指符合本站商辦篩選條件的紀錄與來源欄位，不代表全國所有營業人、完整電話簿或實地查核過的租戶名錄。稅籍地址可能是登記或代收地址；原始地址中的樓層文字照實保留，並未驗證實際使用樓層。無法歸類行政區的地址仍列入名單與總數，不造假座標。

來源檔日期、下載時間、檔案 SHA256、筆數及來源網址均記錄於 `data/catalog.json`。來源未提供逐筆最後異動時間。財政部資料依[政府資料開放授權條款第 1 版](https://data.gov.tw/license)使用；行政區與分類設定亦附來源及授權資訊。

## 功能與效能

- 22 縣市、行政區、產業、資本額、上市櫃、拜訪進度及名稱／統編／地址搜尋。
- 預設篩選資本額 1,000 萬元以上（含），符合條件的上市、上櫃公司優先，其他符合企業仍保留；清單分頁與 CSV 採相同順序。「恢復預設」回到此條件；切換地區保留關鍵字、產業、資本額、上市櫃與拜訪條件，只取消原大樓條件（切換縣市也取消原行政區）。
- 空白分隔的多個關鍵字逐一比對，可跨公司名稱、統編、地址、行業名稱與股票代號等欄位，例如「華懋 中壢」。保留台／臺、全半形及大小寫正規化，中文組字期間不送出未完成的搜尋。輸入建議只採目前符合結果的真實企業。
- 作用中的條件顯示為可單獨取消的標籤。上市櫃與拜訪狀態可組合，產業選單按大類分組並合併同名的批發／零售分類，依第一項登記行業篩選。公司卡片展開後保留全部原始欄位；無結果時提供逐項放寬條件的操作。
- 每 10,000 筆一個資料分片，由 Web Worker 檢索；進度明示完成範圍，結果每頁 40 筆，快取有數量上限。
- 「找大樓」以核對過的名稱／別名／門牌搜尋，不受企業條件限制。名稱精確對應正規化門牌，不推測相鄰號碼；主搜尋也支援名稱與別名。原有地址名錄則依正規化門牌彙整目前結果。企業卡可開啟外部地圖搜尋地址。
- 完成檢索後可匯出所有篩選結果，含原始欄位與來源資訊；超過 100,000 筆請縮小至行政區，或下載官方完整 ZIP，絕不默默截斷。
- 拜訪進度只存在目前瀏覽器，可備份／還原。正式資料以統編固定識別，與舊合成紀錄完全隔離，舊狀態不套用到真實企業。
- 手機名單／地圖／分割模式、鍵盤操作、對話框焦點管理與三種底圖。

## 網站使用方式

路過只看到招牌時：按 **找大樓 → 輸入名稱 → 確認地址 → 選大樓**。例如「世貿帝國」「國際金融廣場」「中壢中國信託」。選取後自動切換地區，清除關鍵字與其他企業條件，保留目前資本額；預設仍為 1,000 萬以上、上市櫃優先。摘要提供門牌、來源與核對日期，按 **查看本棟全部收錄企業** 可取消資本額等限制。

名稱清冊只含已核對大樓，不隨每日企業快照自動增補或重新查證；新增資料需核對公開來源後修改設定並通過建置驗證。本期收錄筆數只計已核對門牌、且符合本站商辦條件的稅籍紀錄；零筆不代表沒有企業。登記企業不是實際進駐名單，也尚未串接內部既有客戶資料。

1. 從搜尋框旁的「切換縣市」選擇範圍，再選行政區；網站僅搜尋已收錄的商辦企業。
2. 輸入公司名稱、統編、股票代號或地址。組合條件用空白分開，例如「華懋 中壢」，停止輸入後自動搜尋，也可按 Enter。
3. 展開「篩選條件」，例如同時選「只看上市櫃」與「尚未拜訪」。點搜尋框下方條件的 × 可單獨取消；「恢復預設」與「清除關鍵字與全部條件」分別保留／取消千萬資本額門檻。
4. 公司卡片的「查看完整資料」可查完整金額與全部登記行業；「查登記地址」開啟外部地圖。「找大樓 → 目前結果的門牌」依目前結果彙整地址，選取後仍保留其他條件。
5. 在卡片更新拜訪狀態。從「更多」匯出所有符合結果的 CSV，或備份／還原本機拜訪紀錄 JSON。CSV 的統編欄在 Excel 匯入時請設為文字。
6. 搜尋框旁「使用說明」有完整教學。無結果時可取消個別條件或換縣市；零筆不代表公司不存在。地圖是行政區概覽，登記地址與商辦分組沒有實地查核進駐狀態。

## 本機執行

需要 Python 3.11+、Node.js 22+；建置不需要第三方 Python 套件。

```powershell
python build_commercial_html.py --download
python serve_local.py
```

首次下載官方來源至被 Git 忽略的 `.cache/official/`；後續不加 `--download` 可使用已驗證的本機快照。Windows 亦可雙擊 `啟動商辦企業地圖.bat`，使用固定的 `http://127.0.0.1:18765/`。JSON 與 Worker 需要 HTTP，不能直接雙擊 HTML。

原始資料約 325 MB，靜態產物大小依本期商辦篩選結果而定。來源與 `data/`、`dist/` 都不提交 Git。前端資產與資料版本分別使用雜湊，避免舊快取混用。

## 驗證與部署

```powershell
python build_commercial_html.py
python -m unittest discover -s tests -p "test_*.py" -v
npm ci --ignore-scripts
npm test
node --check assets/app.js
node --check assets/search-worker.js
```

測試逐筆對帳全部來源欄位與分片雜湊，驗證統編唯一性、來源格式、日期列排除、特殊地址、未知行政區保留、CSV 公式防護、正式紀錄隔離及篩選邏輯。DOM 測試另驗證中文組字、條件組合、地區切換保留關鍵字、空結果復原、完整資料與說明視窗焦點；jsdom 僅用於測試，不隨網站發布。

編輯 `src/index.html` 或 `assets/`；根目錄 `index.html` 是生成檔。推送 `main`、手動執行，或每天台灣時間約 06:17 的 GitHub Actions 排程，會重新下載三個官方來源、完整建置與測試，再部署到原 GitHub Pages。排程可能依 GitHub 負載延後。

來源下載失敗、格式改變、資料明顯不完整、對帳或測試失敗、產物超過 950 MB 時會停止發布，保留前一版。每次成功發布的實際來源日期可在網站查看。**沒有 SMTP、寄信程式或網站郵件通知。**

## 隱私與圖資

拜訪紀錄沒有後端或跨裝置同步，清除瀏覽器資料或使用無痕模式可能遺失，請定期備份。備份僅能套用到相同統編的官方紀錄，不能建立企業資料。

Leaflet 1.9.4 隨站提供，授權見 `assets/vendor/leaflet/LICENSE`。OpenStreetMap、國土測繪中心與 Esri 底圖保留來源標示。外部圖資服務會收到 IP 與請求的地圖範圍；開啟外部地圖搜尋會送出選定登記地址。只有主動按下「我的位置」且允許後才使用定位，本站不儲存位置。
